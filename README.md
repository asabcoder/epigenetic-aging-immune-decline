# epigenetic-aging-immune-decline
This project investigates whether epigenetic age acceleration is associated with measurable changes in immune system composition and function across the human lifespan. Using population-based cohorts with paired DNA methylation and immune profiling data, we will evaluate whether established epigenetic clocks can identify individuals whose biological age exceeds their chronological age and whether this acceleration is associated with markers of immunosenescence, including immune-cell populations, inflammatory biomarkers, and other measures of immune function. Through regression and, where appropriate, longitudinal or survival analyses, we will determine whether epigenetic age provides predictive information about immune decline beyond chronological age and assess the consistency of these relationships across independent cohorts.
